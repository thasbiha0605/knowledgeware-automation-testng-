Knowledgeware Demo Website – TestNG Automation

Project Overview

This project focuses on automating web application testing using Java, Selenium WebDriver, and TestNG on the Knowledgeware Demo Website.

Tools & Technologies

- Java
- Selenium WebDriver
- TestNG Framework
- Eclipse IDE

Test Scenarios

The following web elements were tested:

1. Text Fields – Entering user information.
2. Radio Buttons – Selecting radio button options.
3. Dropdown – Selecting options from dropdown lists.
4. File Upload – Uploading a file through the form.

Test Framework

TestNG is used to organize and execute automation test cases.

Test Execution

Run the TestNG test suite using the testng.xml file.

Test Results

Test execution results and screenshots are included in this repository.

Project Purpose

To gain practical experience in Selenium WebDriver automation using Java and TestNG.
